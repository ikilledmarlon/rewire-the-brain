FILE SIZE TIPS
═══════════════════════════════════════════════════════════

Kling exports can be heavy (5-15MB each). For best GitHub Pages performance:
  ▸ Compress with HandBrake (free) → "Web Optimized" preset → ~500KB-1MB each
  ▸ Or use https://www.veed.io / https://www.freeconvert.com to drop quality slightly
  ▸ Target: under 2MB per video, total repo under 15MB

If repo grows past 25MB, GitHub may warn — consider hosting videos on Cloudflare R2
or Bunny.net CDN and updating the src attributes in index.html to point to those URLs.
